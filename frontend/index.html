How It Works

Four steps from prompt to Pull Request

1

Link Your Repo

Connect your GitHub repository to AgentForge with a single URL paste.

2

Give a Prompt

Describe the task you want done — a new feature, a bug fix, a new file.

3

Agent Works in Sandbox

The AI agent clones your repo inside an isolated Docker environment and writes the code.

4

Review the PR

A Pull Request is raised on your GitHub. You review, approve, and merge.
